# F28 — Cadena de suministro y SDD seguro

> Ficha de implementación SDD. Peso máximo: 8 KB.

## Objetivo

Integrar controles de seguridad continua en el harness y la cadena de suministro para que las regresiones de seguridad no dependan de revisión manual.

## Alcance

- `uv lock --check` y `uv sync --locked`.
- Escaneos: `pip-audit`/OSV, `bandit`, `semgrep`, `gitleaks`.
- CI/pre-commit con gates de seguridad.
- Self-host o pinning con SRI de Tailwind y Google Fonts; CSP sin `unsafe-inline` cuando sea posible.
- Tests de headers, auth, privacidad, backups y escaneos.
- Documentación de respuesta a vulnerabilidades.
- Actualización de `init.sh` para incluir controles de seguridad no destructivos.

## Fuera de alcance

- SIEM, WAF comercial, escaneo DAST continuo.
- Reemplazo del stack frontend.

- gitleaks sin secretos.
- pip-audit/bandit/semgrep sin High/Critical.
- CSP/assets con pinning o self-host.
- `init.sh`/CI ejecutan gates.
