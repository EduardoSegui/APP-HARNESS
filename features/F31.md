# F31 — E2E Playwright y video demo

> Ficha de implementación SDD. Peso máximo: 8 KB.

## Objetivo

Automatizar un flujo real de la aplicación con Playwright y generar una demo reproducible con datos ficticios, mostrando login ADMIN con TOTP, alta, auditoría, tablero y acciones administrativas.

## Alcance

- Playwright como dependencia de desarrollo.
- Servidor Uvicorn y SQLite temporal por test.
- Admin demo efímero con contraseña + MFA TOTP ya configurado.
- Flujo E2E: login, alta, auditoría, tablero, reapertura de aprobada y baja lógica.
- Grabación de video con Playwright.
- GIF corto embebido y MP4 enlazado en README.
- Documentación para regenerar la demo.
- Sin datos reales, Internet, Ollama ni Google Authenticator real.

## Fuera de alcance

- Integrar Chrome DevTools en runtime.
- Agregar endpoints de demo a producción.
- Dependencia Playwright en runtime.
- Video en CI obligatorio o Git LFS.
- Cambiar lógica de F30.

## Clarificación

- [x] El video muestra desafío TOTP, no setup QR (recomendación A).

- [x] Video principal con flujo local determinístico, sin Ollama.

## Seguridad y privacidad

- Credenciales y secreto TOTP generados en memoria/temp, no versionados.
- Servidor enlazado a `127.0.0.1`, `ALLOWED_HOSTS` local, `COOKIE_SECURE=false` solo HTTP local.
- Video sin tokens, CSRF, secretos MFA ni recovery codes.
- Base temporal eliminada incluso ante fallo.
- Datos ficticios con emails `@example.test`.
